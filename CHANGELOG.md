# 📜 Changelog

All notable changes to TokenGrid will be documented in this file.

## [1.0.0] - 2026-10-27
### Added
- Initial release of the TokenGrid Omarchy plugin.
- Precision 1100x650 floating window rule integration via Hyprland v0.55+ Lua API (```looknfeel.lua```).
- Ghostty process isolation configuration (```gtk-single-instance = false```) with unique title matching.
- QML bar widget integration for Omarchy panels.
